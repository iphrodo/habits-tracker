# Розгортання «Вільно» на Vercel і Turso

Застосунок зберігає дані у віддаленій SQLite-сумісній базі Turso, тому його можна розгортати на Vercel без постійного локального диска.

1. Встановіть Turso Cloud через Vercel Marketplace для цього проєкту. Додайте URL і token до Production і Preview як `STORAGE_TURSO_DATABASE_URL` та `STORAGE_TURSO_AUTH_TOKEN`; застосунок також розуміє стандартні назви інтеграції `TURSO_DATABASE_URL` і `TURSO_AUTH_TOKEN`. Не додавайте ці значення до Git.
2. У Vercel додайте `NUXT_TRUSTED_ORIGIN` зі своїм HTTPS-доменом, наприклад `https://vilno.vercel.app`. Після підключення власного домену замініть значення на нього.
3. Якщо є локальні записи в `data/vilno.sqlite`, виконайте один раз `npm run migrate:local-to-turso`. Команда переносить attempts, досягнення, receipts і прочитані картки, але зупиниться, якщо в Turso вже є дані, щоб нічого не перезаписати.
4. Злийте гілку застосунку в `main` і запустіть Deploy у Vercel. Nuxt preset і команда `npm run build` визначаються автоматично.
5. Після розгортання відкрийте `GET /api/tracker`: перший запит створить потрібні таблиці. Перевірте активну спробу, перезапуск і позначку прочитаної мудрості з іншого браузера.

Для локальної розробки скопіюйте `.env.example` у `.env` і додайте ті самі Turso змінні. Резервні копії та відновлення керуються з Turso; не копіюйте SQLite-файл із Vercel, бо його там немає.
