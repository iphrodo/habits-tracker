# Розгортання «Вільно»

Потрібен Node.js 22.13+ (або новіший), HTTPS reverse proxy та постійний локальний диск. Не розгортайте на платформі з ephemeral filesystem.

1. Скопіюйте `.env.example` у захищений env-файл. Пароль і облікові записи для MVP не потрібні.
2. Локально використовуйте `./data/vilno.sqlite`. Для production задайте абсолютний `NUXT_DATABASE_PATH` поза каталогом застосунку та public, наприклад `/var/lib/vilno/vilno.sqlite`, і створіть каталог з правами для користувача, що запускає Node.js.
3. Виконайте `npm ci`, `npm run build`, потім `NODE_ENV=production node .output/server/index.mjs`. Міграції застосовуються під час першого серверного старту.
4. Перед оновленням зробіть копію. Для production-вузла застосовуйте SQLite Online Backup API або коротко зупиніть процес і виконайте `NUXT_DATABASE_PATH=... VILNO_BACKUP_DIR=... node scripts/backup.mjs`. Зберігайте резервні копії поза volume застосунку; скрипт лишає останні 7.
5. Для відновлення зупиніть процес, скопіюйте потрібну резервну копію на шлях `NUXT_DATABASE_PATH`, перевірте власника й права доступу, потім запустіть попередню сумісну збірку. Записи після моменту копії буде втрачено.

Перевірка після розгортання: `GET /api/health`, створення спроби, перезапуск процесу й тестове відновлення копії в ізольованому середовищі.
